# FrostBridge branding

Approved working concepts: **stacked** and **horizontal** FrostBridge logo, both blue with bridge + frost motifs.

## Required asset set
- FrostBridge-stacked.png / .webp / .svg
- FrostBridge-horizontal.png / .webp / .svg
- Print artwork for round 2.25-inch and 3-inch buttons/pins, with a bleed and a clear safe zone

## Usage
Use the horizontal lockup for website headers and the stacked lockup for posters, signage and square placements. For small buttons, use the emblem without the tiny subtitle where possible. Provide vendors vector (outlined) artwork or high-resolution 300 dpi raster art and always check their specific trim, bleed and safe-area templates.

## Production note
Generated image assets and printer proofs must be reviewed before publication. The vector files require text/contour inspection at production size. Never use individual participant imagery as a proxy for disability status.
