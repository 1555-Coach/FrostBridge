# FrostBridge branding assets

The **stacked** and **horizontal** logo designs are working program identities, inspired by FRC 1555 CryoFrost and E3RC.

## Available in this repository
- [Stacked SVG](FrostBridge-stacked-traced.svg) · [PNG](FrostBridge-stacked.png) · [WebP](FrostBridge-stacked.webp) · [300-dpi PNG](FrostBridge-stacked-print-300dpi.png)
- [Horizontal SVG](FrostBridge-horizontal-traced.svg) · [PNG](FrostBridge-horizontal.png) · [WebP](FrostBridge-horizontal.webp) · [300-dpi PNG](FrostBridge-horizontal-print-300dpi.png)

## Preferred uses
- Horizontal: website banners, headers, letterhead.
- Stacked: posters, signs, handouts, cards and large stickers.
- For small pins/buttons, prefer a **simplified emblem-only design** without unreadable subtitle. Obtain the manufacturer's trim, bleed and safe-area template before creating production art.

## Quality and governance
SVG artwork is **automatically traced from approved raster concepts**. Check edge quality, text shapes and suitability with the printer before manufacturing. “300 dpi” refers to the tagged print export at its intended physical dimensions; it does not make raster artwork a true editable vector.

Temporary source links are not dependencies of the delivered assets. A one-time workflow at `.github/workflows/bootstrap-branding.yml` generated the repo files. This program is not affiliated with Hidden Disabilities Sunflower.

The separately delivered local branding ZIP also includes **2.25-inch and 3-inch button mockup proofs**; these should be sent as visual references only, not final die-line files.
